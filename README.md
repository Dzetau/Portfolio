# Портфолио 

Добро пожаловать в моё портфолио! Этот репозиторий представляет собой коллекцию проектов в области **аналитики данных** и **BI-аналитики**.Здесь собраны практические работы, демонстрирующие навыки обработки, исследования и визуализации данных, а также умение извлекать аналитические выводы для решения бизнес-задач

---

##  Проекты

### Python — Анализ данных

**Исследование стартапов**

Анализ рынка стартапов, структуры финансирования и динамики возврата инвестиций с целью выявления перспективных направлений для вложения капитала.

**Основные задачи:**
- Загрузка и предобработка данных.
- Обработка пропусков и дубликатов.
- Исследовательский анализ данны(EDA).
- Инжиниринг признаков и сегментация рынка.
- Анализ выбросов и структуры финансирования.
- Исследование динамики инвестиций.
- Анализ возврата средств.
- Формирование выводов и рекомендаций.

**Инструменты:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.

### Power BI — Business Intelligence

Проекты по визуализации данных, разработке интерактивных дашбордов и созданию аналитических отчётов для поддержки принятия бизнес-решений.

**Основные задачи:**
- Разработка интерактивных дашбордов.
- Анализ ключевых показателей эффективности (KPI).
- Подготовка и преобразование данных.
- Создание вычисляемых показателей.
- Анализ бизнес-метрик.
- Визуализация данных и результатов исследований.

**Инструменты:** Power BI, DAX, Power Query.

## Цель портфолио

 Основная цель данного портфолио — продемонстрировать практические навыки работы с данными, аналитическое мышление и умение превращать исходные данные в понятную визуальную информацию. Каждый проект представляет собой отдельную практическую работу, направленную на решение определённых аналитических задач.
