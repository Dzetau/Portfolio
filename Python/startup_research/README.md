# Исследование стартапов

Анализ рынка стартапов, структуры финансирования и динамики возврата инвестиций для выявления перспективных направлений вложения капитала.

## О проекте

**Тип проекта:** Исследовательский анализ данных

**Направление:** Data Analytics / Investment Analytics

**Инструменты:** Python, Pandas, NumPy, Matplotlib, Seaborn

**Автор:** Диана Мактупова

**Дата выполнения:** 23.12.2025

### Бизнес-задача

Финансовая компания заинтересована в изучении закономерностей финансирования стартапов и оценке перспектив выхода на рынок с целью покупки и дальнейшего развития компаний.

**Цель исследования** — подготовить данные, изучить динамику и структуру финансирования стартапов, определить наиболее перспективные сегменты рынка и оценить динамику возврата инвестиций.

## Данные

В исследовании используются два набора данных:

| Датасет | Описание |
|:---|:---|
| `cb_investments.csv` | Информация о стартапах, привлечённых инвестициях, раундах финансирования и характеристиках компаний |
| `cb_returns.csv` | Данные о возвратах инвестиций по различным типам финансирования в разрезе лет |

## Этапы исследования

### 1. Загрузка и предобработка данных

- Загрузка и первичное изучение датасетов.
- Анализ пропущенных значений.
- Поиск и удаление явных и неявных дубликатов.
- Приведение названий столбцов к единому стилю.
- Преобразование типов данных.
- Обработка пропусков и оптимизация структуры данных.

### 2. Инжиниринг признаков

- Классификация компаний по продолжительности финансирования.
- Выделение компаний с единичным финансированием.
- Разделение компаний по срокам привлечения инвестиций.
- Сегментация рынков на массовые, средние и нишевые.

### 3. Анализ выбросов и структуры финансирования

- Определение типичных объёмов финансирования.
- Поиск аномальных значений.
- Анализ доли компаний с аномальным финансированием по сегментам.
- Определение границ исследуемого периода.
- Изучение популярности и объёмов различных типов финансирования.
- Анализ возвратов по инвестиционным инструментам.

### 4. Анализ динамики финансирования

- Исследование изменения среднего объёма одного раунда финансирования.
- Анализ количества инвестиционных раундов по годам.
- Определение сегментов рынка с растущим объёмом финансирования.
- Исследование годовой динамики возврата инвестиций.
- Сравнение эффективности различных типов финансирования.

## Итог

В рамках проекта проведён комплексный анализ исторических данных о стартапах.

Исследование позволило выявить особенности структуры финансирования, определить перспективные сегменты рынка, изучить динамику инвестиционной активности и оценить изменения доли возврата средств по различным типам финансирования.

Полученные результаты могут использоваться в качестве аналитической основы для предварительной оценки инвестиционных направлений и формирования стратегии работы с венчурными инвестициями.
